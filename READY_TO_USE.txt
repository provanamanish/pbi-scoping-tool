🚀 HOW TO START USING

OPTION 1: PowerShell (Easiest)
  1. Open PowerShell in this folder
  2. Run: .\START_TOOL.ps1
  3. See the startup message with access URLs
  4. Open browser to: http://127.0.0.1:5000

OPTION 2: Command Line
  1. Open Command Prompt in this folder
  2. Run: START_TOOL.bat
  3. See the startup message with access URLs
  4. Open browser to: http://127.0.0.1:5000

OPTION 3: Any OS (Manual)
  1. Open terminal
  2. Navigate to tool folder
  3. Run: python3.14 app.py
  4. Open browser to: http://127.0.0.1:5000

🆘 TROUBLESHOOTING

PROBLEM: Can't start tool
SOLUTION: Check Python is installed (python3.14 --version)
          Run from correct folder
          Check firewall isn't blocking

PROBLEM: Button is greyed out
SOLUTION: Make sure both .pbix files are selected
          Check file format is correct

PROBLEM: Connection refused
SOLUTION: Make sure tool is still running
          Try refreshing browser (F5)
          Restart tool if needed

PROBLEM: Analysis takes forever
SOLUTION: Large reports need 30-60 seconds (normal)
          Don't close browser tab while processing
          Wait for spinning indicator to stop

PROBLEM: Results look wrong
SOLUTION: Field names often differ between reports
          This is expected and normal
          Review yellow matches manually

→ See GETTING_STARTED.md for more troubleshooting
