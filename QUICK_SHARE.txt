TROUBLESHOOTING:
================================================================================

Colleague can't access?
   1. Check server is running (you should see port 5000 message)
   2. Verify both on same network (run: ipconfig)
   3. Try computer name instead: http://IDAP-VM2:5000
   4. Restart: .\START_TOOL.ps1

Slow access?
   1. Large .pbix files take time to upload
   2. Wait 2-5 seconds per page
   3. Restart for fresh start

Port 5000 blocked?
   1. Edit app.py: change port=5000 to port=5001
   2. Share new URL: http://172.20.240.102:5001
