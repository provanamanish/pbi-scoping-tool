📖 User Guide

📤 Step 1: Upload Reports
Click each box to select your Power BI files (.pbix)
  • Choose OLD report first
  • Choose NEW report
  • Click "Analyze reports"
Tip: Files stay local, nothing uploaded to internet
📄 Step 2: Select Page
Pick which page you want to map fields for
  • Use dropdown to select
  • Preview shows field count
  • Can repeat for multiple pages
Tip: Do one page at a time, export after each
🎯 Step 3: Review Results
Check field matches and confidence scores
  • 🟢 Green = Exact match (safe)
  • 🟡 Yellow = Review before use
  • 🔴 Red = Create manually
Tip: Export results for documentation
❓ Need Help?
  • Files won't upload? Check .pbix format
  • Tool is slow? Wait 30-60 seconds
  • Low confidence? Names might differ
✨ Quick Tips
  • Use Search to filter results
  • Download CSV or Excel
  • Review yellow matches manually
